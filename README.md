# Календарь встреч компании

Веб-инструмент для планирования встреч между сотрудниками.

## Возможности

- **Добавить встречу** — тема, дата, время начала/окончания и участники (кто с кем).
- **Смотреть чужие встречи** — общее расписание в режиме **День** / **Неделя**,
  с навигацией по датам.
- **Защита от накладок** — слот нельзя занять, если у любого из участников
  на это время уже есть другая встреча. Пересекающиеся встречи отклоняются
  с понятным сообщением («Анна уже занята на встрече …»).
- **Управление сотрудниками** — добавление и удаление.

## Стек

- Ruby 3.4, Ruby on Rails 7.2
- PostgreSQL (расширение `btree_gist`)
- Server-rendered ERB + Hotwire (Turbo), importmap; без сборки фронтенда
- Локаль `ru`, часовой пояс Москвы

## Модель данных

- `Employee` — сотрудник (`name`, `email`).
- `Meeting` — встреча (`title`, `starts_at`, `ends_at`).
- `MeetingParticipant` — связь many-to-many между встречами и сотрудниками
  (с денормализованным временем встречи — см. ниже).

**Защита от накладок в два уровня:**

1. **Валидация** (`app/models/meeting.rb`) — две встречи конфликтуют, если
   `starts_at < other.ends_at AND ends_at > other.starts_at` и у них есть общий
   участник. Даёт пользователю понятное сообщение («Анна уже занята…»).
2. **Exclusion constraint в PostgreSQL** (`btree_gist` + `tsrange`, ограничение
   `no_overlapping_meetings` на `meeting_participants`) — гарантирует отсутствие
   пересечений на уровне БД даже при одновременных запросах (race condition).
   Время встречи денормализовано на строку участника, т.к. ограничение работает
   в пределах одной таблицы. Нарушение перехватывается в контроллере.

При удалении сотрудника его участие в встречах убирается каскадно
(`dependent: :destroy`); сами встречи сохраняются.

## Интерфейс выбора времени

Время задаётся датой и выпадающими списками часов (00–23) и минут (00–59) —
без формата AM/PM. Списки реализованы кастомным виджетом
(`app/javascript/custom_select.js` + helper `custom_select`), значение хранится
в скрытом поле, поэтому форма работает как обычная. По умолчанию — сегодня, 00:00.

## Запуск

```bash
bin/rails db:create db:migrate db:seed   # первый запуск
bin/rails server                         # http://localhost:3000
```

Подключение к БД настроено на локальный PostgreSQL через системного
пользователя (peer-аутентификация) — см. `config/database.yml`.

Демо-данные (`db/seeds.rb`): 5 сотрудников и 3 встречи.

## Как пользоваться

1. Откройте `/` — увидите расписание на сегодня. Переключайтесь День/Неделя,
   листайте даты стрелками.
2. `+ Новая встреча` — заполните тему, выберите дату и время, отметьте
   участников (минимум двух).
3. Если время пересекается с чужой встречей у кого-то из участников —
   форма покажет, кто именно занят.
4. Открыть встречу из списка можно кликом по названию; там же — кнопка удаления.
5. `Сотрудники` — добавить или удалить сотрудника.
